# Expense Tracker (Python)

This is a simple Python console project to track daily expenses.

## Features
- Add Expense
- View All Expenses
- Calculate Total Expense

## Technologies Used
- Python
- Lists
- Loops
- Conditional Statements

## How It Works

1. User selects an option from the menu.
2. User enters expense amount and category.
3. Expenses are stored in a list.
4. Program calculates total expenses.

## Example Output

All Expenses:

Amount: 500 | Category: Food  
Amount: 200 | Category: Travel  

Total Expense: 700
